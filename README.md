# रक्षाबंधन सरप्राइज वेबसाइट 🎁 (Raksha Bandhan Surprise Website)

यह एक खास, खूबसूरत और पूरी तरह से स्टैटिक वेबसाइट है जिसे एक बड़े भाई की तरफ से अपनी छोटी बहन को रक्षाबंधन पर भेजने के लिए डिज़ाइन किया गया है।

इसे बिना किसी कोडिंग नॉलेज के कस्टमाइज़ किया जा सकता है और Vercel पर मुफ्त में होस्ट किया जा सकता है।

## 🛠 तस्वीरें कैसे जोड़ें (How to Add Photos)

यह वेबसाइट **बिना किसी तस्वीर के भी पूरी तरह काम करती है**। अगर आप कोई तस्वीर नहीं डालते हैं, तो वहां एक खूबसूरत 'चित्र' (Placeholder) दिखाई देगा।

जब आप अपनी तस्वीरें डालना चाहें:
1. अपनी तस्वीरों को `assets/` फोल्डर के अंदर रखें। (जैसे: `memory1.jpg`, `memory2.jpg`)
2. `script.js` फाइल को किसी टेक्स्ट एडिटर में खोलें।
3. सबसे ऊपर `CONFIG` सेक्शन में जाएं।
4. `memories` के अंदर, `image: ""` की जगह अपनी तस्वीर का नाम लिखें, जैसे `image: "assets/memory1.jpg"`।
5. सेव करें।

## 🎵 संगीत कैसे जोड़ें (How to Add Music)

म्यूजिक भी पूरी तरह से वैकल्पिक (Optional) है।
1. अपना म्यूजिक फाइल `assets/` फोल्डर में डालें और उसका नाम बिल्कुल `music.mp3` रखें।
2. `script.js` खोलें।
3. सबसे नीचे `CONFIG` सेक्शन में `musicFile: ""` को बदलकर `musicFile: "assets/music.mp3"` कर दें।

## ✍️ नाम और संदेश कैसे बदलें (How to Edit Messages)

आपको HTML या CSS फाइल को छूने की कोई जरूरत नहीं है।
1. `script.js` खोलें।
2. सबसे ऊपर `CONFIG` ऑब्जेक्ट में `sisterName`, `letter`, और कार्ड्स के सारे संदेश एक ही जगह मौजूद हैं।
3. बस वहां टेक्स्ट बदलें और सेव करें!

## 🚀 Vercel पर डिप्लॉय कैसे करें (How to Deploy to Vercel)

यह एक 100% स्टैटिक वेबसाइट है, इसलिए यह बिना किसी बिल्ड स्टेप के Vercel पर चल जाएगी।

1. इस पूरे फोल्डर को एक नए GitHub Repository में अपलोड करें। **ध्यान रखें कि `index.html` रिपॉजिटरी के बिल्कुल बाहर (Root) होना चाहिए**, किसी फोल्डर के अंदर नहीं।
2. [Vercel](https://vercel.com/) पर जाएं और **Add New Project** पर क्लिक करें।
3. अपना GitHub Repository इंपोर्ट करें।
4. **महत्वपूर्ण:** Vercel की सेटिंग्स को बिल्कुल वैसा ही छोड़ दें। Build Command या Output Directory में कुछ न डालें।
5. **Deploy** पर क्लिक करें।
6. जो लिंक मिलेगी, उसे अपनी बहन को भेजें! 🎉
